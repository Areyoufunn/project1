# ⚠️ ATURAN VISUAL SETIAP SLIDE

| Rule | Detail |
|---|---|
| **1 hook** | Selalu 1 kalimat pembuka — bold, besar, atas slide |
| **Maks 3 poin** | Tidak lebih dari 3 bullet atau 3 kolom per slide |
| **Ikon > teks** | Setiap konsep = ikon + 2-3 kata, bukan kalimat |
| **Angka besar** | Setiap slide punya minimal 1 angka besar yang terlihat dari 3 meter |
| **1 warna aksen** | Satu warna highlight per slide — tidak perlu banyak warna |
| **Screenshot nyata** | Slide 3, 4, 7 wajib punya mockup UI asli — bukan ilustrasi |
